Общий прогонщик сценариев для Shore пока не написан: probe-раннер (`Tools/Run-WarsBotsProbe.ps1`) умеет только Steelmill IA. Сценарии ниже запускаются серверным прогоном без клиента на CI-сборке точного SHA. Флаги — профиль владельца Shore-15 (`E:/WarsBots/Visual/Shore-15-*/preset.json`): 15 ботов, `wb_ps_capture`, `wb_ps_buy`, `wb_ps_doors`, `wb_trap_recovery`, `wb_bot_*` профиля, плюс `wb_log 2` и `wb_move_trace 1`. Метрики считаются по `*.bots.log`. Команды ботов определяются по чётности номера: нечётные — команда 1.

- **Флаги сверх профиля:** `wb_bot_pro_fire 1` (в профиле уже есть).
- **Длительность:** 10 мин.
- **Метрики:**
  - убийства своих: `GameRules::KillPlayer`, где команды target и killer совпадают, а это не самоубийство;
  - попадания в живых союзников: `FRIENDLY HIT`;
  - удержания огня: `NOFIRE reason=friendly`;
  - все убийства.
- **PASS:** 0 убийств своих; не больше 2 попаданий в живых союзников; убийств не меньше 20.
- **Последний результат:** PR #16, сборка `0a41e055`: убийств своих 0, попаданий 2, удержаний 21, убийств 31. GREEN.

### shore-loot-one-claimer
- **Что проверяет:** за одним трофеем идёт один бот (SPEC-002, строки 5–7).
- **Флаги сверх профиля:** `wb_bot_tactics 1` (в профиле уже есть).

- **Последний результат:** PR #16, сборка `0a41e055`: 9 пропусков. Одновременных идущих не считали, поэтому PASS частичный.
