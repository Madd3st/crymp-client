# Демки

Внутриигровая запись матча, как в Counter-Strike: записать → посмотреть → разобрать цифрами.

## Формат `wbdemo/2`

Файл `*.wbdemo` пишет сервер (20 кадров/с). Внутри:
- **FRAME** — позиция, скорость, взгляд, здоровье, энергия костюма каждого игрока;
- **BRAIN** — что бот думает: цель, видимые враги, кто его атаковал;
- **INTENT** — что бот хотел сделать: куда идти, бег/спринт, прыжок, режим костюма, стрелять ли;
- **INV** — оружие и патроны; **EVENT** — убийства, подборы, возрождения.

Спецификация: `Docs/Research/SteelmillTriage/DEMO_FORMAT.md`. Клиент может писать дополнение `.wbdemo.client`
(взгляд человека), Triage сам его совмещает.

## Разбор

```
python3 Tools/SteelmillTriage/steelmill_triage.py demo <файл>.wbdemo [--client <файл>.wbdemo.client]
```

Метрики: «гуляние» прицела (°/с), ошибка прицела, время реакции, смены решений в минуту, время до основного оружия,
убийства по оружию. Первая демка (24.10): 61 % убийств с пистолета, 15 смен решения в минуту, реакция 0.8 с —
это «до», от этого меряем улучшения.

## Проигрывание

2D-просмотр уже есть (`steelmill_triage.py replay` → HTML). Проигрывание внутри игры (как в CS) — в планах, после
навигации на двух картах.
