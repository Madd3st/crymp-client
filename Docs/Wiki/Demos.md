# Демки, логи и видео

Для разбора нужны наблюдения одного и того же запуска. Демка фиксирует серверные данные, MOVE TRACE — диагностические строки, видео — картинку человека. Их сопоставляют по времени/отметкам; одна только сводная метрика не объясняет поведение.

## Что сохранять

| Артефакт | Зачем |
| --- | --- |
| `*.wbdemo` | Кадры, состояния и события; конкретная схема зависит от версии codec |
| Журналы сервера и ботов | Параметры, состав, решения, ошибки и путь |
| Видео клиента | Видимое движение, камера, взаимодействие и ощущение игры |
| preset/build/manifest и summary | Связать артефакты с SHA и данными |
| Restore receipt | Доказать возврат текущих данных после теста |

C150 складывает фактические файлы в `Sessions/` своего профиля. Обычные пути движка строятся от `%LOCALAPPDATA%\WarsBots`; проверяй реальные пути в журнале, особенно при ином окружении процесса.

## Формат и инструменты

Схему сверяй с [BotDemoCodec.h](https://github.com/Madd3st/crymp-client/blob/b8b444d6c858f27a1fdde0d93b25a318cafc6937/Code/CryGame/Bots/BotDemoCodec.h) и [BotDemoRecorder.cpp](https://github.com/Madd3st/crymp-client/blob/b8b444d6c858f27a1fdde0d93b25a318cafc6937/Code/CryGame/Bots/BotDemoRecorder.cpp) на SHA записи. Историческая [спецификация](https://github.com/Madd3st/crymp-client/blob/warsbots/research/steelmill-triage/Docs/Research/SteelmillTriage/DEMO_FORMAT.md) полезна для терминов, но не заменяет актуальный codec. Проверяй заголовок, версию, полноту хвоста и хеш; повреждённый хвост нельзя молча считать полным матчем.

Инструменты анализа — `Tools/SteelmillTriage/`, отчёты плейтестов — `Tools/PlaytestReport/` на triage. Начни с их README и `--help`, затем укажи конкретный вход. Старые команды/форматы могут не соответствовать новой записи. Наличие скрипта игрового playback в QA не подтверждает, что он готов для любой версии демо.

## Практика для владельца

Нажми F8 у странного события. Для видео полезен `r_displayInfo 1`; отсутствие оверлея не обесценивает видео. Дай время, ожидаемое действие и имя сессии. Сохрани несколько секунд до события. Не удаляй исходную запись после получения красивой картинки отчёта.

Пример проверенного архива: C149, 1 638 кадров, целый хвост, одна US-сущность, SHA256 демо `f151a843c14843b2be63e62fec58281132d15385004a22229e461db19fde9ecc`. [Отчёт](https://github.com/Madd3st/crymp-client/blob/warsbots/feature/weapon-goals/Docs/Coordination/C149_UPPER_SHORE_RESULT.md). Такой архив подтверждает конкретный маршрут, не всю карту.
