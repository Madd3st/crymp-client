# Навигация

Как бот понимает, куда можно пройти.

## Сейчас в игре: граф точек

`BotNav` строит граф из точек на карте и лучей между ними. Работает на Steelmill, но плохо переносится на другие карты:
на Steelmill 13 из 36 спавнов оказались вне основной части графа, часть точек — «тупики».

## Дальше: навигационная сетка Recast/Detour

**Recast** — стандартная библиотека (её используют Unity, Unreal и др.): по геометрии уровня строит «ковёр» из
многоугольников, по которым может пройти игрок заданного размера. **Detour** ищет по нему путь.

Процесс:
1. Сервер выгружает столкновительную геометрию карты (`wb_geom_export`) → OBJ.
2. `Tools/RecastBake/recast_bake` запекает сетку с размером игрока (радиус 0.35–0.4 м, рост 1.8 м, ступенька 0.5 м,
   уклон 45°) и находит места для **прыжков**: спрыгнуть (до 4 м), обычный прыжок (до 1 м вверх), прыжок с силой
   костюма (до 4.7 м вверх). Каждая дуга проверяется лучами по реальной геометрии — сквозь стены не прыгаем.
3. Результат: картинка, JSON (какие спавны и оружие достижимы), список прыжков.

### Результат на 24.10 (ячейка 5 см)

| Карта | Спавны: пешком → с прыжками | Оружие (туда и обратно) |
| --- | --- | --- |
| Steelmill | 36/36 → 36/36 | 54 → 88 из 109 |
| Quarry | 30 → 32/32 | 89 → 108 из 108 |
| Outpost | 35/35 → 35/35 | 117 → 121 из 123 |
| Armada | 19 → 34/40 | 72 → 125 из 156 |

Выводы: сетка работает на всех картах; **прыжки обязательны** (на Steelmill половина оружия на крышах и мостках);
на Armada нужны лестницы и лифт (особые переходы). Подробно — `Docs/Research/SteelmillTriage/RECAST-BAKE-2026-10-24.md`,
картинки — `Docs/Research/SteelmillTriage/evidence/recast/`.

## Вертикальный геймплей

Crysis — вертикальная игра: крыши, мостки, прыжок с силой. Поэтому прыжки — не украшение, а часть навигации:
переходы-прыжки входят в сетку как «off-mesh links», а модуль `BotJumpLink` их исполняет.
