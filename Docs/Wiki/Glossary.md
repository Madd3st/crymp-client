# Словарь

| Слово | Значение |
| --- | --- |
| **CryMP** | современный клиент/сервер для мультиплеера Crysis Wars |
| **IA / PS** | Instant Action (все против всех) / Power Struggle (командный режим) |
| **Спавн** | точка появления игрока |
| **Навсетка (navmesh)** | многоугольники, по которым можно ходить; по ним ищется путь |
| **Recast / Detour** | библиотеки: построение навсетки / поиск пути по ней |
| **Off-mesh link** | переход вне сетки: прыжок, спрыгивание, лестница, лифт |
| **SCC / основная часть** | кусок карты, где из любой точки можно попасть в любую и вернуться |
| **Прыжок с силой** | прыжок в режиме Strength нанокостюма, до ~4.7 м вверх, тратит энергию |
| **MOVE TRACE** | журнал позиций игроков раз в 250 мс |
| **Triage** | наши Python-инструменты анализа логов/демок (`Tools/SteelmillTriage`) |
| **Парный прогон** | два одинаковых теста «до/после» изменения |
| **Регрессия** | изменение, после которого стало хуже, чем было |
| **Переключатель (флаг, cvar)** | консольная переменная, включающая новое поведение |
| **C-xxx / DS-xxx / D-xxx** | задача Codex / задача DeepSeek / решение владельца (OC-xxx — старые задачи OpenCode, больше не используются) |
| **X-xxx** | ответ Codex на задачу |
| **NOW** | строка «чем занят сейчас» в начале ответного файла агента |
| **Демка (wbdemo)** | запись матча для просмотра и разбора |
