# Словарь

| Термин | Значение |
| --- | --- |
| CryMP | Клиент/сервер мультиплеера Crysis 2007, основа нынешнего порта WarsBots |
| IA / PS | Instant Action (свободный бой) / Power Struggle (команды, базы, экономика и захват) |
| SHA | Точный идентификатор Git-коммита; имя ветки может указывать уже на другой код |
| CI | Автоматические тесты и сборка на GitHub; зелёный результат не заменяет игровой тест |
| Пресет / рецепт | Карта, режим, боты, effective CVar и условия конкретного запуска |
| Navmesh | Проходимая поверхность из полигонов; её наличие не доказывает физическое исполнение пути |
| Recast / Detour | Запекание навмеша / запросы пути на нём |
| Off-mesh link | Особый переход между участками сетки; в текущих профилях drop/jump/Strength, не готовый лифт или лестница |
| SCC / компонента | Группа связности; важно направление переходов и возможность вернуться |
| Strength jump | Прыжок в режиме силы; допустимость зависит от физики, разбега и конкретных данных, не единой обещанной высоты |
| Native water plane | Уровень воды из игры; не обязательно совпадает с координатой ног пловца |
| Project / Reach / FindPath | Проекция на сетку / достижимость / построение пути |
| MOVE TRACE | Периодический журнал состояния и движения; частота определяется рецептом |
| NAVfallback | Диагностический переход на запасной путь навигации; причину нужно разбирать |
| Oracle | Проверка, различающая известный дефект и исправление на фиксированном входе |
| Gate / preflight | Условие допуска / проверка эффективного рецепта перед игрой |
| Manifest | Состав и контрольные хеши согласованного набора данных/пакета |
| Runtime | Реальное выполнение в игре; отличается от офлайн-симуляции |
| Regression | Ухудшение ранее проверенного поведения после изменения |
| Default | Значение по умолчанию; включение в одном пресете не меняет default проекта |
| wbdemo | Запись состояний и событий; читать codec соответствующего SHA |
| C- / DS- / D- / X- | Задача Codex / задача DeepSeek / решение владельца / ответ Codex |
| NOW | Текущая работа в начале outbox, не постоянное описание роли |
| DONE = SHA | Завершённый результат сопровождается коммитом и доказательствами |

Связанные страницы: [первое знакомство](Getting-Started), [проверки](Testing-and-Evidence), [процесс](Team-and-Process).
