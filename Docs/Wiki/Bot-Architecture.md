# Как устроен бот

Бот — это **серверный игрок**: сервер CryMP создаёт обычного актёра `CPlayer` и каждый кадр сам выдаёт ему ввод
(движение, взгляд, стрельба, прыжок, режим костюма). Для игры бот ничем не отличается от человека — те же правила
физики, оружия и урона. Никаких читов: бот не стреляет сквозь стены и не бегает быстрее людей.

## Цикл одного кадра

```
  мир (позиции, здоровье, оружие, звуки)
            │
   ┌────────▼────────┐
   │   Blackboard    │  «доска»: что бот знает о себе и мире на этот кадр
   └────────┬────────┘
   ┌────────▼────────┐
   │     Brain       │  решает, ЧТО делать: идти за оружием, искать врага, драться, отступать
   └────────┬────────┘
   ┌────────▼────────┐
   │ Nav / Movement  │  КАК дойти: путь по графу/сетке, обход препятствий, прыжки, спринт, темп
   ├─────────────────┤
   │ Targeting / Aim │  куда смотреть и когда стрелять
   ├─────────────────┤
   │ Weapons / Suit  │  какое оружие держать, какой режим костюма включить
   └────────┬────────┘
   ┌────────▼────────┐
   │   Locomotion    │  превращает решения в ввод игрока (кнопки и мышь)
   └─────────────────┘
```

## Модули в коде (`Code/CryGame/Bots/`)

| Файл | Что делает |
| --- | --- |
| `BotManager` | создаёт/удаляет ботов, команды `wb_*`, общий тик |
| `BotInstance` | один бот: связывает все модули |
| `BotBlackboard` | снимок состояния на кадр (здоровье, оружие, может ли двигаться) |
| `BotBrain` | выбор цели поведения: оружие / охота / бой |
| `BotNav`, `BotReachability` | граф навигации по карте, достижимость целей |
| `BotMovement`, `BotLocomotion` | следование по пути, застревания, ввод движения |
| `BotPace`, `BotPacePolicy` | темп: когда бежать, когда спринтовать, когда идти |
| `BotTargeting`, `BotAimControl` | выбор врага и наведение |
| `BotCombat`, `BotFireControl` | поведение в бою, стрельба очередями |
| `BotWeapons` | выбор и смена оружия, подбор |
| `BotSuit` | режимы нанокостюма (сила, скорость, броня, невидимость) |
| `BotMoveTrace`, `BotLog` | журналы для анализа (MOVE TRACE, события) |
| `BotGeometryExport` | выгрузка геометрии карты для офлайн-навигации |
| `BotReviveGuard`, `BotTrapWatchdog` | защита от застревания при возрождении и в ловушках |
| `BotSpectator` | режим наблюдателя для съёмки |
| `CryMPEngineAdapter` | прослойка к движку CryMP |

## Новые модули (ветка `warsbots/research/claude-modules`)

Чистая логика без движка, с юнит-тестами; встраиваются по очереди:

- **BotGoalArbiter** — выбор цели без «дёрганья»: бот держит решение минимум 1–3 с, переключается только по
  важным причинам (враг рядом, получил урон, цель пропала). Сейчас боты меняют решение ~15 раз в минуту.
- **BotJumpLink** — исполнение прыжка по заранее найденному месту: подход, разбег, толчок, полёт, приземление.
- **BotPerception** — восприятие как у человека: конус зрения 110°, время на «заметить», невидимость костюма
  (видно только вблизи или при выстреле), слух выстрелов.
- **BotAimModel** — человеческий прицел: быстрый рывок мышью к цели (с недо/перелётом), плавное ведение, лёгкая
  дрожь руки без «кругов». Уровни навыка: новичок / обычный / ветеран / элита.
- **BotLookPolicy** — куда смотреть без врага: на точку в ~3 м впереди по пути; на место интереса — только если
  до него ничего не загораживает. Против «взгляда в стену» (на демке: вбок > 90° с 32 % до 3–5 %).
- **BotWeaponRank** — сила оружия по дистанции (SCAR/FY71 — средняя, дробовик — вблизи, снайперки — далеко,
  пистолет — запасной) и ценность подбора: за SCAR стоит пройти дальше, чем за ещё одним пистолетом.
- **BotMoverLink** — как ехать на лифте: дойти до кнопки, вызвать, дождаться, встать, доехать, выйти (Armada).
