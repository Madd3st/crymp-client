# Как устроен бот

Бот — это **серверный игрок**: сервер CryMP создаёт обычного актёра `CPlayer` и каждый кадр сам выдаёт ему ввод
(движение, взгляд, стрельба, прыжок, режим костюма). Для игры бот ничем не отличается от человека — те же правила
физики, оружия и урона. Никаких читов: бот не стреляет сквозь стены и не бегает быстрее людей.

## Цикл одного кадра

```
  мир (позиции, здоровье, оружие, звуки)
            │
   ┌────────▼────────┐
   │   Blackboard    │  «доска»: что бот знает о себе и мире на этот кадр
   └────────┬────────┘
   ┌────────▼────────┐
   │     Brain       │  решает, ЧТО делать: идти за оружием, искать врага, драться, отступать
   └────────┬────────┘
   ┌────────▼────────┐
   │ Nav / Movement  │  КАК дойти: путь по графу/сетке, обход препятствий, прыжки, спринт, темп
   ├─────────────────┤
   │ Targeting / Aim │  куда смотреть и когда стрелять
   ├─────────────────┤
   │ Weapons / Suit  │  какое оружие держать, какой режим костюма включить
   └────────┬────────┘
   ┌────────▼────────┐
   │   Locomotion    │  превращает решения в ввод игрока (кнопки и мышь)
   └─────────────────┘
```

## Модули в коде (`Code/CryGame/Bots/`)

| Файл | Что делает |
| --- | --- |
| `BotManager` | создаёт/удаляет ботов, команды `wb_*`, общий тик |
| `BotInstance` | один бот: связывает все модули |
| `BotBlackboard` | снимок состояния на кадр (здоровье, оружие, может ли двигаться) |
| `BotBrain` | выбор цели поведения: оружие / охота / бой |
| `BotNav`, `BotReachability` | граф навигации по карте, достижимость целей |
| `BotMovement`, `BotLocomotion` | следование по пути, застревания, ввод движения |
| `BotPace`, `BotPacePolicy` | темп: когда бежать, когда спринтовать, когда идти |
| `BotTargeting`, `BotAimControl` | выбор врага и наведение |
| `BotCombat`, `BotFireControl` | поведение в бою, стрельба очередями |
| `BotWeapons` | выбор и смена оружия, подбор |
| `BotSuit` | режимы нанокостюма (сила, скорость, броня, невидимость) |
| `BotMoveTrace`, `BotLog` | журналы для анализа (MOVE TRACE, события) |
| `BotGeometryExport` | выгрузка геометрии карты для офлайн-навигации |
| `BotReviveGuard`, `BotTrapWatchdog` | защита от застревания при возрождении и в ловушках |
| `BotSpectator` | режим наблюдателя для съёмки |
| `CryMPEngineAdapter` | прослойка к движку CryMP |

## Модули спринта (ветка `warsbots/feature/claude-sprint`, всё за переключателями)

Чистая логика без движка, с юнит-тестами (`Tests/`); движок подключается тонкой прослойкой в `BotBrain`/`BotCombat`/`Player.cpp`.

| Модуль | Переключатель | Что делает |
| --- | --- | --- |
| **BotLookPolicy** | `wb_bot_look` | куда смотреть без врага: ~3 м вперёд по пути, только если взгляд не упирается в стену; места интереса — при чистой видимости |
| (turn cap) | `wb_bot_turn_cap` | поворот взгляда каждый кадр с пределом по навыку (400–900 °/с) вместо рывков 10 раз/с |
| **BotWeaponRank** | `wb_bot_weapon_rank` | сила оружия по дистанции и ценность подбора (SCAR > пистолет; Hurricane понижен) |
| **BotGoalArbiter** | `wb_bot_arbiter` | бой / охота / оружие / роуминг с окнами приверженности — меньше «дёрганья» |
| **BotPerception** | `wb_bot_perception` | конус зрения 110°, время заметить, невидимость; слух выстрелов и спринта в Speed |
| **BotAimModel** | `wb_bot_aim_model` | рывок к цели + ведение + дрожь руки по навыку |
| **BotSuitPolicy** | `wb_bot_suit_policy` | одно решение о костюме за тик: падение/урон/бой → броня, Strength для прыжков, Speed на переходах |
| **NavMeshCore** | `wb_bot_navmesh` | пути по запечённому Detour-мешу; связные части с учётом направления |
| **BotJumpLink** | `wb_bot_jump_links` | исполнитель прыжков по связям меша: подход, костюм, разбег, прыжок, приземление; неудачная связь банится |
| **BotWeaponHandling** | `wb_bot_weapon_handling` | лазер всегда (кроме невидимости), зум на дальних целях |
| **BotVantage** | `wb_bot_vantage` | снайперы (Marksman/Defender с DSG1/Gauss) занимают, держат и меняют снайперские точки |
| **BotReplicaSmooth** | `wb_bot_client_smooth` (клиент) | клиент сглаживает шаги направления/взгляда бота — без «ступенек» |
| (имена) | `wb_bot_name_profile` | имя с уровнем: `WarsBot_02 [Normal/Assault]` |

Зрителю теперь видны настоящие патроны бота (раньше показывало 0/0 — сервер не слал патроны клиенту без канала).
