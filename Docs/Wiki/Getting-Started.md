# Первое знакомство

## Что именно мы строим

Цель — боты, с которыми интересно играть в обычный мультиплеер Crysis: находить оружие, перемещаться по сложной карте, использовать костюм и сражаться. Instant Action — свободный бой; Power Struggle добавляет команды, базы, экономику, захват точек и технику. Поэтому удачная перестрелка на Steelmill сама по себе не подтверждает готовность Shore.

**Бот живёт на сервере.** Клиент показывает реплицированного актёра; отдельного человеческого сетевого канала у бота нет. Отсюда отдельные задачи: серверное взаимодействие с дверями, передача состояния наблюдателю, корректное возрождение и выбор команды.

## Что посмотреть первым

1. Открой [текущий статус](Status-and-Roadmap): он отделяет проверенные сценарии от дальнейших планов.
2. Для игры возьми готовый профиль из [инструкции запуска](Running-and-Playing). Самостоятельно собирать проект для показа не требуется.
3. В Steelmill сначала посмотри бой восьми ботов, затем попробуй режим наблюдателя.
4. Shore сейчас показывает конкретный маршрут одного US-бота. Не оценивай по нему готовность экономики, техники или всей карты.
5. Если заметил странность, поставь F8-отметку и сохрани время события. [Инструкция по баг-репорту](Troubleshooting) объясняет, что приложить.

## Три вещи, которые часто путают

| Термин | Значение |
| --- | --- |
| Билд | Клиент и сервер, собранные из точного Git SHA |
| Пресет | Карта, режим, боты, переключатели и условия запуска |
| Данные карты | Навмеш, связи переходов, тактические точки и их манифест |

Даже один билд с разными пресетами или данными может вести себя по-разному. Поэтому отчёт должен фиксировать все три части.

## Если ты инженер

Начни с [карты репозитория](Repository-Map), затем [маршрута инженера](Engineering-Guide). Игровой код находится в `warsbots/feature/claude-sprint`. Ветка `weapon-goals` хранит QA-отчёты и инструменты, её игровой код устарел. Прежде чем изучать функцию, проверь ветку и SHA.
