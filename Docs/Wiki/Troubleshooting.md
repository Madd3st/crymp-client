# Разбор проблем

## Если готовый профиль не запускается

| Наблюдение | Следующее действие |
| --- | --- |
| Не найден Crysis | Проверь `game-dir.txt`: он должен указывать на установленную игру |
| Пакет повреждён / не совпал хеш | Запусти `CHECK.cmd`; восстанови исходный пакет, не меняй контрольные хеши ради обхода |
| Игра уже работает / порт занят | Нормально заверши предыдущую свою сессию; чужой сервер или клиент автоматически не закрывается |
| Профиль остановился до открытия клиента | Сохрани текст ошибки и последний каталог `Sessions`; это отказ readiness, не готовый игровой результат |
| Shore отклоняет спавн | Профиль рассчитан на проверенный верхний US-спавн. Не телепортируй бота и не запускай цикл случайных повторов |
| Окно launcher закрыли раньше игры | Закрой Crysis, затем `RESTORE.cmd` в том же профиле; сохрани каталог сессии |
| Нет `Archived and restored` | Не начинай другую карту. Сохрани ошибку и проверь результат восстановления; при закрытом клиенте используй `RESTORE.cmd` |
| F6/F7 не следят за ботом | Нужны Steelmill/Instant Action и штатный режим наблюдателя. Shore/PS такой режим не поддерживает |

Не удаляй Memory/Navmesh и Sessions, чтобы «починить запуск»: там могут находиться текущие данные и снимок для восстановления.

## Если бот ведёт себя странно

Во время игры нажми F8, запиши время и место. По возможности включи `r_displayInfo 1` для видео и покажи несколько секунд до и после события. Видео полезно для видимого маршрута и взаимодействия игрока, но диагноз требует сопоставления с логом/демо того же запуска.

| Симптом | Что искать в данных |
| --- | --- |
| Стоит у стены | Цель, результат пути, оставшиеся углы, progress, физическое положение |
| Не выходит из воды | swim/grounded, native water plane, точки начала/цели Detour, NAVfallback |
| Прыгает без результата | Вход/тип/направление link, фазы исполнителя и физическое приземление |
| Не открывает дверь | Какая дверь и серверный вызов взаимодействия, сообщения GameRules/сети |
| Резко дёргается только у зрителя | Серверный trace против клиентского видео, версия пары EXE и клиентское сглаживание |
| Не захватывает точку | Реальная цель PS, принадлежность/радиус, достиг ли области; близость сама по себе не равна захвату |

## Что прислать

```text
Профиль и SHA: Steelmill или Shore, версия из build.json
Сессия: имя каталога Sessions и время F8/события
Ожидал: ...
Получилось: ...
Карта/место/команда: ...
Видео: файл и временной интервал
Менял ли preset/данные вручную: ...
```

Сохрани каталог сессии целиком. Далее — совместный разбор с DeepSeek и связная пачка исправлений. Повторный прогон без нового вопроса обычно не добавляет знания.
