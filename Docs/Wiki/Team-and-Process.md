# Команда и процесс

Над проектом работают владелец и три ИИ-агента с разными ролями.

| Кто | Роль |
| --- | --- |
| **Владелец** (Madd3st) | ставит цели, играет и даёт обратную связь, принимает решения (D-xxx) |
| **Codex** | пишет игровой код, собирает, гоняет тестовые серверы — единственный, кто меняет `warsbots/feature/*` |
| **Claude** | координатор: статусы, очередь, анализ логов и демок (Triage), вердикты, офлайн-инструменты, модули логики без движка |
| **OpenCode** | исследование кода движка «только чтение», ревью чужих изменений |

## Почта

Агенты общаются через файлы в `Docs/Research/Coordination/MAILBOX/`:
- `TO_CODEX.md` (задачи C-xxx), `TO_OPENCODE.md` (OC-xxx) — от Claude;
- ответы — `Docs/Coordination/TO_CLAUDE.md` (Codex), `OPENCODE_TO_CLAUDE.md` (OpenCode);
- `DECISIONS.md` — решения владельца (D-001…), `PROTOCOL.md` — правила.

Каждый агент после задачи пушит результат и ждёт новую почту скриптом `Tools/Mailbox/wait_mail.ps1`.

## Как принимается изменение

1. Изменение делается **за переключателем** (выключено по умолчанию).
2. Парный прогон: 15 ботов × 660 с «до» и «после» на одинаковых условиях.
3. Triage считает метрики (скорость, застревания, подборы, убийства, смерти от себя).
4. Claude пишет вердикт, владелец решает — включить по умолчанию или нет.

Правила: без сборок во время игры владельца; не гасить чужие серверы; каждое число — со ссылкой на файл:строку
или лог.
