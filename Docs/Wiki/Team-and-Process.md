# Команда и процесс

Над проектом работают владелец и три ИИ-агента. Роли по решению **D-013** (25.10, экономия лимитов):

| Кто | Роль |
| --- | --- |
| **Владелец** (Madd3st) | цели, плейтесты (весят больше прогонов), решения D-xxx |
| **Claude** | пишет игровой код (`warsbots/feature/claude-sprint`), вердикты по демкам и логам, офлайн-инструменты, документация |
| **Codex** | собирает (MSVC), гоняет пачки тестов, вливает зелёное в `warsbots/feature/weapon-goals`, готовит плейтест-билды; код — только тривиальные исправления компиляции |
| **OpenCode (модель DeepSeek)** | анализ, ревью каждого коммита, спецификации, разбор отчётов; только чтение, своя ветка `warsbots/research/deepseek`, почта `TO_DEEPSEEK.md`, сам берёт задачи из постоянного бэклога |

## Почта

`Docs/Research/Coordination/MAILBOX/` (ветка steelmill-triage): `TO_CODEX.md` (C-xxx), `TO_OPENCODE.md` (OC-xxx),
`DECISIONS.md` (D-xxx), `PROMPTS.md` (стартовые промпты агентов). Ответы: `Docs/Coordination/TO_CLAUDE.md` (Codex, в
weapon-goals), `OPENCODE_TO_CLAUDE.md` (OpenCode, в movement-params). Ожидание почты — `Tools/Mailbox/wait_mail.ps1`.

## Как принимается изменение (пачками)

1. Claude пишет код пачкой, всё за переключателями (по умолчанию выключено), с юнит-тестами.
2. Codex: одна сборка + тесты, смоук 6 ботов, один прогон 15 ботов × 660 с (без фич — контроль, со всеми фичами), демки.
3. Claude считает метрики по демкам и логам, пишет вердикт. Зелёное — Codex вливает.
4. Плейтест владельца с записью → правки → следующая пачка. Включение по умолчанию решает владелец.

Правила: без сборок, пока владелец играет; чужие серверы не трогать; цифры — со ссылкой на файл/лог/демку.
