| Боты | Сложность |

Это **Instant Action, Steelmill, 8 ботов**, по два каждой сложности. Клиент и сервер из одной CI-сборки `abac72a9a1eb02793a2f4ab2b1a72f7c243dd72e`, полный зелёный CI `40890940918`; независимое ревью DS121 `5c12d27b`. Каноническая навигация C119, экспериментальная лестница выключена. Восемь профилей сложности проверяются по реальным строкам создания в серверном журнале до запуска клиента. Проверки упаковки и команд прошли; отдельного нового игрового прогона смешанного состава ради упаковки не было.

Требуется установленный **Crysis 2007**. Ресурсы игры не входят в пакет; путь хранится в `game-dir.txt`, сейчас `E:\Steam\steamapps\common\Crysis`. Пакет расположен на E, установка DLL или перезапись игры не требуются. Порт локального сервера — 46166, привязка 127.0.0.1 и LAN-only.

## Как посмотреть или поиграть

1. Закрой предыдущую игру/сервер и запусти START.cmd. Уже запущенные процессы сохраняются: запуск откажется, вместо того чтобы их завершать.
2. Выбери наблюдателя, чтобы следить за ботами, либо войди в матч обычным способом.
3. **F6/F7** — следующий/предыдущий бот; **F1** — вид от первого лица в режиме наблюдения; **F8** — отметка в журнале.
4. Заверши игру штатно. Окно PowerShell оставь открытым до сообщения о сохранении и восстановлении данных.

Если хочется запустить через PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "E:\WarsBots\Showcases\Steelmill-Classic-abac72a9\Run.ps1"
```

## Проверка, журналы и восстановление

| Файл | Назначение |
| --- | --- |
| START.cmd | Запуск проверенного пакета |
| CHECK.cmd | Проверка хешей/команд без старта игры |
| RESTORE.cmd | Завершить восстановление после прерывания окна; действующую чужую игру не закрывает |
| preset.json | Карта, порт, явные флаги и критические значения |
| build.json, ci-sha256.txt | Точный SHA/CI и согласованная пара EXE |
| package-manifest.json | Хеш каждого файла пакета; не редактировать для обхода проверки |
| Sessions/<метка>/ | Аргументы, эффективные флаги, архив журналов/демо, снимки и результат восстановления |
| last-session.txt | Каталог последнего запуска для RESTORE.cmd |

До запуска создаётся снимок **Memory/Navmesh в том же контексте Windows, где запускается игра**. После выхода сохраняются журналы и демо, затем возвращаются исходные имена, байты и наличие каталогов. Закрывается только собственный сервер с совпадающими PID, путём и временем старта. Если другой клиент ещё работает, восстановление откладывается. Ошибка целостности — повод сохранить журнал, а не менять EXE или манифест вручную.

## Shore пока остаётся диагностикой

Текущий пакет `C:\Users\Magic8\WarsBotsBuild\WarsBots-Preview-abac72a9` **не подтверждает играбельный маршрут**. Бот поднимается, но верхний выход блокируется около 97,93 м; исходный прогон стартует сразу и успевает заблокировать связь лестницы до отложенного возрождения через 60 с. После него повторной попытки лестницы в записи владельца не было. Такой показ не следует повторять как проверку нового исправления.

Видео владельца и клиентский журнал подтверждают успешный проход человека по той же шахте до пола 99,75 м. Исправление серверного выхода бота ещё разрабатывается. Следующая приёмка: новый точный SHA/полный зелёный CI/свежее ревью и **один общий маршрут от нижнего спавна до берега**. Отдельный новый проход без изменения причины сбоя не нужен.
