### Почему вода под подлодкой не в навмеше (бейкер, без ручной разметки)

| Причина | Где |
| --- | --- |
| Вода бейкера — одна плоскость `--water 99.5` | `recast_bake.cpp:510` |
| Клетка с твёрдым над водой (палуба, корпус) — без воды: 0 водных полигонов в боксе корпуса | `recast_bake.cpp:498` |
| `--zmin 99.5` и `--retain-box` от z 90 (только целые треугольники) — ниже 90 у ямы ничего | `recast_bake.cpp:100` |
| Проход под килем — объёмное плавание; навмеш Detour (поверхности + одна плоскость воды) его не выражает никаким параметром | — |
| `start_off_mesh` у бота в яме (Codex 59c1391): бокс старта в воде ≤ 2,8 м вверх, ближайший полигон — палуба в 5,8 м | тест `BotSubSwimTests` |

Поэтому выход — исполнитель плавания вне навмеша; цель — ближайший полигон открытой воды из самого навмеша (15 м у борта). Снижение — штатный `ACTION_CROUCH` в воде: взгляд бота только по горизонту, наклон цели не ныряет.
