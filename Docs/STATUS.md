## Итоги 11.11

### Плейтест владельца 11.11 (ночь, Shore-02, пакет 38e63072 = dev + #46 + #48)

Пакет прошёл окно 600 с Codex 10.11 (стоят NK 19,0 % / US 10,5 %, p95 1,64 мс), но в игре:

- **США не выходят из бассейна подлодки:** бегают по кругу, лестницу не берут, не ныряют. Лог (Codex, архив `E:/WarsBots/QA/Shore02-20261111/`): первый `LADDER no_grab` на 35 с банит единственную лестницу для всех до конца уровня (`CancelLadder(...,true)` → `BanLink`), отдельной строки бана нет; #41 (нырок) в пакете не было. Окно это пропустило: бег по кругу не считался «стоят». Фикс бана — **#52** (`wb_bot_ladder_ban` OFF): первый сбой — только этот бот обходит связь 30 с, для всех — 2 бота или 3 сбоя за 120 с, снимается через 120 с; единственный выход снова пробуется.
- **Замороженный MOAC/MOAR бот пропадал с сервера** (#3, #9, #13 до конца матча). Удаления в логе подтверждены, сама заморозка в логе не пишется. Путь — `CGameRules::ShatterEntity`: не игрок → скрыть и удалить через 0,15 с; у бота канал 0. Фикс без флага — **#51**.
- **На энергии стоят в центре зоны** и ничего не делают → SPEC-005b п. 10: двигаться внутри зоны между укрытиями (**#54**, доки).
- Хотелка: элита ложится на дальней дистанции → бэклог боя (**#55**, доки).
