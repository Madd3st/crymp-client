# C-019 geometry export: code checkpoint

`wb_geom_export [path.obj]` is diagnostic, explicit, local IA only, no bots/real players.
Default destination: `%LOCALAPPDATA%/WarsBots/Geometry/<level>.obj` and sibling
`.spawns.json`, `.items.json`, `.geometry.json`. Z-up, metres, full terrain XY footprint,
z -4096..4096. OBJ header and metadata carry exact source SHA. Existing bundles
are not overwritten. Metadata is published last; missing metadata means incomplete.

Static player-colliding parts only; collision proxy preferred, correct part world
position/quaternion/scale applied once. Native heightfield resolution and hole callback;
meshes, oriented boxes,16segment cylinders/spheres/capsules. Streaming bounds memory;
15M triangle cap aborts rather than publishing a truncated export. Unknown geometry
counts are reported, so coverage is not silently treated as complete. Dynamic/rigid/living
objects excluded. No runtime navgraph or actor change.

C++ primitive tests verify triangle counts, nondegenerate outward winding and bounds.
MSVC x64 Release experimental client/server compiled. Offline validation helper:
`python -B Tools/Test-WarsBotsGeometry.py <map.obj>` (run after real exports).
