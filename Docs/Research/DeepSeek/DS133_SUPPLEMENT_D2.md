## §1 — const-сигнатура исправлена

- `bool CPlayer::NeedsWarsBotLadderPhysicsExit()` — без `const` (`Player.cpp:7463`, `Player.h:641`), что
  соответствует реальному SDK: `CActor::IsFrozen()` не const (`Actor.h:966`).
- Мок выровнен: `bool IsFrozen(){return frozen;}` (`Tests/test_bot_ladder_physics_exit_caller.py:71`), то
  есть расхождение, из-за которого unit-job прошёл на `085`, устранено.
- Все вызовы предиката не const (`PrePhysicsUpdate`, `ProcessWarsBotLadderPhysicsExit`,
  `SetWarsBotLadderExitPhysics`), поэтому сигнатура ничего не ломает.
- `d2` расширил условие: `character && (!animations || GetAnimIDByName(...)<0)` — отсутствие
  анимационного реестра теперь тоже даёт право на физический выход, но только при реальном персонаже и
  всех прежних условиях (owned server-бот, `ladder=1`, `onLadder && exiting`, живой, не frozen, не ragdoll).
  Это осознанное расширение: при `null` реестре клип всё равно недоступен, а нативный путь остаётся для
  случая, когда реестр есть и клип зарегистрирован.

## §2 — фильтр геометрии исправлен

- `const int collisionFlags=geom_colltype0|geom_colltype_player;` — это **ровно документированное значение
  по умолчанию** для `geomFlagsAny` (`physinterface.h:2329`), то есть запрос не может быть слабее дефолта.
- Используется в **обоих** вызовах `PrimitiveWorldIntersection` (overlap и sweep) как `geomFlagsAny`.
- Лучи пола/поддержки используют `rwi_stop_at_pierceable | (collisionFlags<<rwi_colltype_bit)` — то есть
  коллтип-маска 0x3 (static + player), а не прежняя «только player».
- `floorMask` (static/terrain/rigid/sleeping) больше не включает `ent_living`: живые блокируют тело, но не
  считаются полом; для overlap/sweep маска по-прежнему `floorMask|ent_living`.
- Фикстура теперь проверяет именно то, что раньше не проверялось: `flagsOK` требует точное слово
  `geom_colltype0|geom_colltype_player` у PWI и декодирует маску у лучей; добавлен fault 7 «static colltype0
  wall», который старый player-only фильтр пропустил бы, а новый ловит; контроли registered-clip-noop и
  foreign-collider-override сохранены.
- Остаточная оговорка (не блокер): физика — закрытая DLL. Существующие вызовы в `PlayerView.cpp:470/489`
  и `BotLocomotion.cpp:97-99` передают в этот же параметр сдвинутую форму, поэтому нельзя статически
  доказать, что движок читает 7-й аргумент как geometry flags. Но выбранное значение — документированный
  default, и это максимально защищённый вариант из доступных без исходников физики.
