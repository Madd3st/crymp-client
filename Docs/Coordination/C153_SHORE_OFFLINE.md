# C153 / DS098: нижние спавны Shore — офлайн-разбор

Источник DeepSeek: `2d8fb24a`, [DS098_SHORE_LOWER_SPAWNS.md](https://github.com/Madd3st/crymp-client/blob/2d8fb24a/Docs/Research/DeepSeek/DS098_SHORE_LOWER_SPAWNS.md). Данные — архив владельца `S150S-20261028-222902`, E223 navmesh, native export `a943e070` и прежние C146/C149. Нового Shore-запуска и изменений данных нет.

Codex независимо повторил запросы настоящим NavMeshCore/Detour из игрового checkout: `build/ds098-verification/result.log`. В копии диагностического probe добавлен завершающий NUL перед `LoadLinkKinds`: исходная версия передавала `vector<char>::data()` как C-строку без явного терминатора. Игровой код и сам mesh не менялись.

## Подтверждено

| Проверка | Результат |
| --- | --- |
| Native US2 в неудачном показе | group537, spawn545, `(2114.500,1887.875,90.575)`; после падения на пол Z≈90.10, grounded, swim0 |
| Клиент / завершение | Не запускался; archive/restore завершены, исторические receipts и байты снимков перепроверены |
| 124 native spawn points на E223 | 113 дают Project=true, 11 — false |
| 12 спавнов ниже уровня 99.5 | 11 не проецируются; spawn530 ошибочно проецируется с 90.38 на 102.71, +12.34 м |
| Старт из нижнего spawn545 | `start_off_mesh`; путь к проверенному верхнему выходу не подтверждён |
| Верхний маршрут C149 | Его PASS сохраняется для конкретного верхнего старта; это не покрытие нижней палубы |

Для нижнего сухого корпуса native water level — sentinel, а не 99.5; высота ниже моря сама по себе не означает, что актёр плывёт. Одна проверка `Project==true` тоже недостаточна: ложная привязка spawn530 показывает необходимость контролировать слой и смещение.

Проверка пяти native capture destinations от верхнего spawn510 по тому же probe: 64/316/579/654 дают путь, 344 — `other_component`. Это уточняет старую заметку о 316: от этого верхнего старта путь есть, но не доказано, что исчезло ограничение префикса для любого другого старта. В игре по-прежнему нет подтверждённого захвата.

## Что требует дальнейшего доказательства

- Согласованный bake внутренних сухих поверхностей и перехода в воду. Наличие вершин корпуса во входном OBJ не доказывает проходимость готового маршрута.
- Естественный выход с нижней палубы: отдельно сопоставить верхний/лестничный и показанный человеком путь через воду/под корпусом. Обязательность именно лестничного контроллера из одного отсутствующего меша не следует.
- Водные query callers для услышанной цели, оружия и tactical spots. Их потенциальный сухой query box не является причиной конкретного отказа spawn545: там отсутствует стартовая область.
- Слой и допустимое смещение проекции должны проверяться согласованно в выборе спавна и последующих запросах пути; нельзя принять верхний пол за нижний.
- Отдельно остаются известные отверстия покрытия и цель344. Большой средний процент проекций их не закрывает.

Предложение DS098 перебрать спавны до подходящего верхнего не принято в C153: это обход неподдерживаемой нижней палубы, а не исправление маршрута. Геометрические связи сквозь корпус, teleport, ослабление C150 gate и случайные повторные игры не использовались. Замороженный пакет не изменён; рядом с ним добавлено описание известного ограничения.

Этот пункт C153 выполнен как диагностика и независимое офлайн-подтверждение, а не как исправление всей Shore. Игровая приёмка текущей пачки относится к связанным целям/оружию на Steelmill.
