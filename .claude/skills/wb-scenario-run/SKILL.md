---
name: wb-scenario-run
description: Прогнать сценарии WarsBots из спеки или каталога Docs/scenarios через существующий probe/triage-харнесс и свести результат в PASS/FAIL. Использовать до кода (ожидается RED) и после (ожидается GREEN).
---

1. Возьми сценарии из указанной спеки (`Docs/specs/NNN-*.md`) или из `Docs/scenarios/<карта>.md`.
2. Запускай только через существующие инструменты (`Tools/`, probe-раннер, triage с `summary.json`).
   Соблюдай `AGENTS.md`: игру локально не собирать, только CI-пара EXE точного SHA; живые Memory/Navmesh не подменять;
   чужую игру не останавливать.
3. Для каждого сценария запиши: имя, SHA, PASS/FAIL, ключевая метрика, путь к сырым логам.
4. Результат — одна таблица в ответе и строка «Сценарии» для `REPORT.md`. JSON-квитанции в `Docs/Coordination/` не создавай.
5. Если сценарий нельзя автоматизировать — так и скажи и добавь его в чек-лист плейтеста вехи.
