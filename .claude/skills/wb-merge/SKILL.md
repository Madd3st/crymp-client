---
name: wb-merge
description: Подготовить и выполнить мерж PR WarsBots в warsbots/dev — проверка стека, CI, ревью, флагов. Использовать когда владелец говорит «мержи» или когда открытых PR больше двух.
---

1. Перечисли открытые PR в `warsbots/dev` и их базы. Если открытых больше 2 — сначала мерж, новые задачи не начинать.
2. Для каждого PR проверь: база = `warsbots/dev` или предыдущий PR; `git merge-base --is-ancestor` подтверждает,
   что ни один коммит из предыдущих PR не выпал.
3. CI зелёный на точном SHA, есть ревью Codex, есть ссылка на спеку (кроме мелких багфиксов).
4. Мержи только по явному «мержи» владельца. Без force-push, без push в upstream и master.
5. После мержа: удали ветку PR на origin (с тегом `archive/<дата>/<ветка>`), обнови `Docs/FLAGS.md` и `Docs/STATUS.md`.
